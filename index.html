Why Strip Markdown & AI Boilerplate?

Copying responses from ChatGPT, Claude, DeepSeek, or Gemini into Microsoft Word, Google Docs, corporate emails, Slack, or CMS often introduces unwanted asterisks (**bold**), hashes (# Header), code backticks, and robotic polite filler. DeMkDown parses text into an Abstract Syntax Tree (AST) to reliably strip formatting without regex corruption.

01

AST-Based Parser

Built on unified and remark AST. Unlike naive regular expressions that break on inline formulas ($x * y * z$) or code symbols, DeMkDown accurately parses hierarchical Markdown nodes.

✓ Zero regex pitfalls
02

AI Tone & Fluff Filter

Eliminates conversational AI filler phrases in both English and Chinese: opening preambles ("Sure, here is..."), transition fluff, and trailing boilerplate ("Hope this helps!").

✓ 100% benchmark accuracy
03

Smart Table Formatting

Converts pipe tables into neatly aligned monospace plain text (with East Asian CJK double-width calculation), Excel-ready TSV, or standard CSV format.

Frequently Asked Questions

Common questions about stripping Markdown, cleaning AI outputs, and data privacy.

How do I strip Markdown formatting from ChatGPT, Claude, or DeepSeek? ▾

Simply copy the AI response and paste it into DeMkDown. The tool parses the text into an Abstract Syntax Tree (AST) in real time and strips headings, bold asterisks, blockquotes, and code fences, producing clean plain text ready to paste into Word, Google Docs, Slack, or email.

Why is AST parsing better than Regex for removing Markdown? ▾

Regex-based cleaners use simple pattern matching that often corrupts text containing asterisks (e.g., mathematical formulas like $a * b * c$), C/C++ pointer dereferences, or nested code blocks. DeMkDown uses a full AST parser (Remark/Unified) that understands nested document structure, safely extracting plain text without false deletions.

How does the AI Tone & Fluff filter work? ▾

DeMkDown includes an AI Tone Cleaner engine with benchmarked patterns for English and Chinese. It detects and strips opening pleasantries ("Certainly! Here is...", "好的，以下是为您整理的内容："), conversational transitions, and trailing boilerplate ("Hope this helps!", "Let me know if you have questions."), leaving only pure substantive content.

How does DeMkDown handle Markdown tables? ▾

DeMkDown offers 4 table output formats: Aligned Plain Text (computes character display widths, including East Asian wide characters, to ensure column alignment in monospace font), TSV (Tab-Separated Values for pasting directly into Excel or Google Sheets), CSV (Comma-Separated Values), or Markdown preservation.

Is my text data private and secure? ▾

Yes, 100%. DeMkDown runs entirely client-side inside your web browser. No text, prompts, or documents are ever uploaded to remote servers, and there is zero tracking or telemetry. It is completely safe for confidential business documents, code, and proprietary data.

Is there an API or programmatic way to strip Markdown? ▾

Yes! DeMkDown provides a serverless Cloudflare Pages Functions API endpoint at POST /api/demark that accepts JSON payloads with Markdown text and configuration options, returning clean plain text and detailed conversion metrics.

Cloudflare Pages Functions API

DeMkDown provides a native Cloudflare Pages Function at /api/demark powered by Cloudflare Workers V8 runtime and standard Web Request / Response APIs.

cURL Example:

curl -X POST https://demkdown.alocal.host/api/demark \
  -H "Content-Type: application/json" \
  -d '{
    "markdown": "# 标题\n好的，以下是为您整理的内容：**高可用**。\n希望对您有所帮助！",
    "options": {
      "outputMode": "plain",
      "stripHeadings": true,
      "stripEmphasis": true,
      "cleanAIFluff": true
    }
  }'

JavaScript / Fetch Example:

const response = await fetch('/api/demark', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    markdown: rawAIText,
    options: { outputMode: 'plain', cleanAIFluff: true }
  })
});
const { success, result, stats } = await response.json();
console.log(result);
