Cloudflare Pages Functions API

DeMark provides a native Cloudflare Pages Function at /api/demark powered by Cloudflare Workers V8 runtime and standard Web Request / Response APIs.

cURL Example:

curl -X POST https://demark.pages.dev/api/demark \
  -H "Content-Type: application/json" \
  -d '{
    "markdown": "# Hello World\nCertainly! This is **bold** text.",
    "options": {
      "outputMode": "plain",
      "stripHeadings": true,
      "stripEmphasis": true,
      "cleanAIFluff": true
    }
  }'

JavaScript / Fetch Example:

const response = await fetch('/api/demark', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    markdown: rawAIText,
    options: { outputMode: 'plain', cleanAIFluff: true }
  })
});
const { success, result, stats } = await response.json();
console.log(result);
